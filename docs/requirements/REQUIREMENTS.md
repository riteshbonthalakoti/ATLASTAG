# System Requirements: AtlasTag

## Core Requirements
- **Functionality**: Global asset tracking (GNSS + Cellular).
- **Form Factor**: Slim and portable. [PENDING: Final dimensional constraints based on research]
- **Power**: Battery-powered (Li-Po), low-power operation with sleep/wake cycles.
- **Connectivity**: LTE-M / NB-IoT.

## Features (Minimum Viable Product)
- GNSS positioning
- Remote location telemetry transmission
- Motion detection (wake-on-motion)
- Battery voltage/status monitoring
- Local telemetry storage (when cellular connection drops)

## Future Expandability Options
- BLE
- Wi-Fi positioning
- UWB
- Geofencing
- Intelligent movement detection

## Constraints
- Must be genuinely manufacturable as a physical product (not just dev boards wired together).
- Realistically achievable layout and assembly.
